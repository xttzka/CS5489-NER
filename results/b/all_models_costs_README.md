# Role B model cost handoff

Frozen manifest: `cc20216cd9a430153e9d344eecb3b340bbe3ed46d559c4081ca5885300189d01`. CSV has 162 rows, one per frozen test task. `B_costs_manifest.json` records every input SHA-256 and output SHA-256.

`inference_seconds` times the synchronized predictor call after model/tokenizer loading and after reading prepared token rows. It includes subword tokenization/encoding of prepared words, model forward, decoding, and two synchronized memory snapshots per batch. It excludes dataset preparation, external raw-text/spaCy tokenization, process startup, model loading, and writing predictions. Divide the recorded sentence count by these seconds for throughput. Batch size, length distribution, model, dataset and profiling synchronization differ; these are not uniform end-to-end or production throughput measurements. Parameter counts are taken from the restored inference model; `trainable_parameter_count` counts parameters marked `requires_grad` at inference, which is not independently a record of the optimizer's training parameter groups.

The two MPS allocation columns are maxima of synchronized *batch snapshots*, not exact peak memory. Live tensor allocation and process-level Metal driver allocation measure different things; driver values include cached pools. Apple Silicon has shared unified memory, so neither is dedicated VRAM nor total physical memory. The profiler can miss transient intra-batch maxima. Blank profile fields mean no measurement: a fixed-300 task may reuse a full-set prediction without a fresh profile, while the four representation variants did not generate profiles. Do not borrow the full-set throughput for a subset.

Training wall time is recorded only when the same queue journal contains a matching task_start/task_complete for the exact run. Queue monotonic intervals and one-second-resolution wall-clock intervals are identified separately; both can include startup, loading, epoch work, validation, checkpoint writes and scheduling delays. `training_epoch_seconds_sum` is a separate sum of all explicitly logged epoch timers, available only if each requested epoch and final Done are recorded; it is not total wall time and timing boundaries vary by training script. No cost is inferred for missing history. The same trained model appears in many evaluation tasks, so training values repeat and must not be summed across CSV rows. Historical MPS true peak memory was not recorded.
